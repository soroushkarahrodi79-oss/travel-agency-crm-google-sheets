# Security policy

## Supported versions

Security fixes are provided for the latest release on the `main` branch.

| Version | Supported |
| --- | --- |
| 1.1.x | Yes |
| 1.0.x | Upgrade recommended |

## Private reporting

Do not publish vulnerabilities, customer information, spreadsheet IDs, access
tokens or deployment URLs in a public issue.

Use GitHub's **Report a vulnerability** feature in the repository Security tab.
Include:

- affected version;
- reproduction steps using fictional data;
- expected and observed authorization behavior;
- impact and suggested remediation, if known.

You should receive an initial acknowledgement within seven days.

## Deployment responsibility

This repository contains source code, not a hosted service. Every deployer must
secure their own Google accounts, spreadsheet sharing, user registry, backups,
retention policy and legal compliance.

Never store payment-card numbers, passwords or government identity documents
in this sample CRM.
